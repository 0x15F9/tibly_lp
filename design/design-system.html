Tibly · Anchor

Navy owns structure. Green owns interaction. Gray does the work. A classic serif carries the name. Built for clinical density: high contrast, unambiguous numerals, WCAG AA everywhere.

The five laws

Everything below is an application of these. When a screen feels wrong, one of these has been broken.

Navy owns structure. Chrome, headings, navigation, emphasis. Navy never sits on a control that performs an action.
Green owns interaction. Buttons, links, active indicators, focus, selected states. Green is never decoration. One sanctioned crossover: the green active-tab indicator inside navy chrome.
One solid green button per screen. It marks the primary action. Everything else is a navy outline, a ghost, or a green-text button.
Statuses are tinted pills with icons — never solid fills. This treatment rule is what lets action-green and success-green share an interface without confusion.
The serif lives at 22px and above. EB Garamond for page titles, record names, marketing. Inter does all body, table, form, and button work — with data features on.

Color

Two brand ramps and a cool neutral ramp. In a typical screen, neutrals cover roughly 80% of pixels; navy and green together should not exceed 15%.

Do and don't

Do

  • One solid green button per screen
  • Serif for the page title, Inter for everything below it
  • Icons on every status pill
  • .font-data on vitals, dosages, prices, dates
  • Navy topbar with the green active indicator
  • Neutral-500 uppercase table headers

Don't

  • Green headers, navy buttons — roles never swap
  • Solid green status badges (pills only)
  • Serif below 22px, ever
  • Two solid green CTAs competing on one screen
  • Pure black text — ink is navy-800 or neutral-900
  • Color as the only carrier of meaning
